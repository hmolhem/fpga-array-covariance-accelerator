\chapter*{Objective}
\addcontentsline{toc}{chapter}{Objective}

\begin{objective}
The objective of this report is to document, from requirements through board evidence, the
controlled translation of an existing floating-point sample-covariance-matrix (SCM) front
end into a traceable fixed-point implementation on the PYNQ-Z2 platform. The work is
bounded to one eight-sensor, 128-snapshot array-processing frame, one selected fixed-point
SCM kernel, one PS--PL--PS interface, and downstream software DOA verification. Every
major technical claim is governed by an explicit gate, acceptance criterion, evidence record,
and engineering interpretation.
\end{objective}

The report is intentionally complete in architecture before the implementation is complete.
Unexecuted sections are marked PENDING rather than omitted, so the scientific question,
verification method, and evidence location are fixed before results are observed.
